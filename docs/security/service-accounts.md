# Service Accounts

The Service Accounts screen lists all `ServiceAccount` resources across namespaces.

## Columns

| Column | Description |
|---|---|
| Name | ServiceAccount name |
| Namespace | Namespace |
| Secrets | Number of attached secrets / tokens |
| Age | Time since creation |

## Actions

### View YAML

Double-click a row to open the manifest (read-only).
